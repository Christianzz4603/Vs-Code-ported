Code Studio / Overview

Code Studio for Android

An advanced Visual Studio Code port for Android built with Kotlin, Jetpack Compose, Room DB, and Gemini AI Workspace Copilot.

⚡ Production Native `.JAR` Extension Platform
Code Studio now features a compiled extension architecture. Extensions are distributed as `.jar` packages containing compiled Java/Kotlin bytecode, manifest specifications, and native JNI `.so` libraries.

Key Platform Highlights

🤖 Gemini AI Copilot
Full workspace indexing with multi-file refactoring, preview diffs, and instant rollback.
🔌 .JAR Extension Platform
Modular plugin framework supporting bytecode execution and native JNI binary execution.
🔀 Git & Sync Commit
One-click Sync Commit for staging, committing, and pushing branch updates seamlessly.

Quick Quickstart (Building the App)

# Grant executable permission to Gradle wrapper
chmod +x gradlew

# Build Debug APK
./gradlew assembleDebug

# Build Release APK
./gradlew assembleRelease

# Execute local JVM unit tests
./gradlew testDebugUnitTest

Code Studio / Builds & CI/CD

CI/CD & GitHub Actions Workflows

Automated build and documentation deployment pipeline.

Workflow Specifications

The repository includes two automated workflows under .github/workflows/:

  • ci.yml: Validates Kotlin compilation and runs Robolectric unit tests on every pull request.
  • android-build-release.yml: Assembles release APK artifacts upon main branch updates.
  • deploy-github-pages.yml: Automatically builds and deploys this documentation portal to GitHub Pages.
Core Features / Gemini AI Copilot

Gemini AI Workspace Copilot

Intelligent workspace indexing and multi-file automated refactoring.

The AI Copilot maintains real-time context of all files, symbols, imports, and diagnostics in your project. It allows you to ask natural language questions or request complex code edits across multiple files simultaneously.

Core Features / Git & Source Control

Git & Sync Commit System

Streamlined source control operations inside Android.

The Source Control panel tracks modified files and provides a one-click Sync Commit button (`Ctrl+Shift+S`) that automatically stages all changes, creates a signed git commit, and pushes to origin/main with status logs in the interactive terminal.

Core Features / Command Palette

Command Palette (`Ctrl+Shift+P`)

Centralized access to all IDE and extension actions.

Type commands or keyboard shortcuts to execute AI bug fixes, git operations, file creation, extension commands, and view toggles instantly.

Extensions / Architecture

Native .JAR Extension Architecture

A modular extension platform designed for performance and security.

Package File Anatomy

Every extension is packaged into a single compiled .jar file containing metadata, bytecode, assets, and optional JNI native libraries:

MyExtension.jar
├── META-INF/
│   └── MANIFEST.MF
├── manifest.json
├── classes/
│   └── com/example/extension/MyExtension.class
├── lib/
│   ├── arm64-v8a/
│   │   └── libextension.so
│   ├── armeabi-v7a/
│   │   └── libextension.so
│   └── x86_64/
├── themes/
├── snippets/
├── README.md
└── LICENSE

Extensions / Native JNI

Native C++/JNI Integration (.so)

Executing high-performance compiled binary libraries inside extensions.

Place compiled C/C++, Rust, or Go shared libraries inside lib/<abi>/ inside your `.jar`. Declare the `"native_code"` permission and `"nativeLibrary"` in `manifest.json`. Code Studio will extract and load the library securely at runtime.

Extensions / Permissions & Security

Permissions & Security Model

Sandboxed permission enforcement.

Every extension request is filtered through a SecurityManager. Unauthorized calls throw a SecurityException to prevent malicious behavior.

Tutorials / 1. Hello World

Tutorial: Building Your First .JAR Extension

Create a basic Hello World extension in Kotlin.

package com.example.hello

import com.example.extension.api.ExtensionContext
import com.example.extension.api.ExtensionLifecycle
import com.example.extension.manifest.ExtensionPermission

class HelloWorldExtension : ExtensionLifecycle {
    override fun onActivate(context: ExtensionContext) {
        context.securityManager.checkPermission(ExtensionPermission.UI_CONTRIBUTION)
        context.uiRegistry.setStatusBarMessage("👋 Hello World Extension Active!", 4000)

        context.commandRegistry.registerCommand("extension.hello.sayHello") {
            context.notificationAPI.showInfo("Hello World from Code Studio Extension!")
        }
    }
}
