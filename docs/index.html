An IDE experience on Android featuring full Jetpack Compose UI, Room DB persistence, Git Source Control, and Gemini AI Workspace Copilot.

✨ Core Capabilities

🤖

Gemini AI Workspace Copilot

Indexed workspace awareness across files, symbols, and diagnostics. Proposes multi-file code refactoring, preview diffs, accept/reject, and instant rollback.

🔀

Git & Sync Commit

Stage modified files, inspect status, and trigger 1-click Sync Commit (automatically staging, committing, and pushing branch updates).

⌨️

Command Palette & Shortuts

Press Ctrl+Shift+P to trigger VS Code commands: AI bug fixes, multi-file refactoring, split editor toggle, and terminal actions.

🖥️

Split Editor & Activity Bar

Side-by-side file editing with synchronized tabs, syntax theme customization, line numbers, and interactive terminal console logs.

🗄️

Room DB Local Persistence

Offline file management powered by Android Room Database with fast transactional state retention.

⚡

CI/CD Release Packaging

Automated GitHub Actions workflow for building release APK artifacts and publishing GitHub Pages documentation.

🚀 Building the Android App

You can compile and package the app using Gradle or run unit tests on any machine:

# Grant executable permissions
chmod +x gradlew

# Build Debug APK
./gradlew assembleDebug

# Build Release APK
./gradlew assembleRelease

# Run Robolectric Unit Tests
./gradlew testDebugUnitTest

📐 Architecture & Tech Stack

  • UI Layer: Jetpack Compose with Material 3 Dynamic Color & Custom VS Code Dark Palette.
  • State Management: ViewModel, Kotlin Coroutines, and StateFlow / collectAsStateWithLifecycle.
  • Database: Room DB with Kotlin Symbol Processing (KSP).
  • Network: OkHttp3 & Rest API integration with Gemini 3.5 Flash.
